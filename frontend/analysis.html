📊 Alur Kerja Analisis Data

1
Import Data
Data diimpor dari file Excel/CSV yang berisi katalog produk laptop dari 4 marketplace.
2
Pembersihan Data
Data dibersihkan menggunakan Pandas: menghapus duplikat, mengisi nilai kosong, dan menstandarkan format.
3
Analisis Deskriptif
Menghitung statistik deskriptif seperti rata-rata, median, dan distribusi harga per kategori.
4
Analisis Kluster
Mengelompokkan laptop berdasarkan harga dan spesifikasi untuk menemukan pola segmen pasar.
5
Visualisasi
Membuat grafik interaktif menggunakan Chart.js untuk memvisualisasikan hasil analisis.
6
Integrasi Database
Hasil analisis disimpan ke database MySQL untuk ditampilkan di website ini.
⚠️ Grafik di atas dihitung dari dataset demo (55 produk). Hasil analisis dengan dataset yang lebih besar akan memberikan insights yang lebih akurat.
